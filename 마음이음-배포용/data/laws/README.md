# 공식 근거 자료 관리

sources.json만 검색 대상으로 사용합니다. 각 항목은 공식 URL, 발행기관, 내용 요약, 시행일, 종료일(해당 시), 검토일과 재검토 기한을 포함합니다. 스키마와 허용 도메인을 lib/laws.ts에서 검증합니다.

2026-11-03 검토: 교원지위법 제19조·제20조, 경기도교육청 2026 교육활동 보호 안내 자료. 제19조의 2026-12-03 시행 개정은 미래 자료로 제외됩니다. 현재 검토 기한은 2027-02-11입니다. 자료 본문과 시행일을 공식 원문에서 다시 확인한 후에만 검토 날짜를 갱신하세요.

교육청 자료는 관할과 맥락이 있는 공식 안내이며 판결 사례가 아닙니다. 가상 CBR 데이터는 공식 법률 근거로 사용하지 않습니다. 근거가 없거나 유효기간 조건을 통과하지 못하면 ‘근거 자료 없음’으로 처리합니다.


2026-11-11 재검토: 제21717호 개정(2026-12-03 시행, 대면·비대면 교육활동 명시, 교육활동에 현저한 지장을 주는 민원 추가)을 언론 보도(한국교육신문 2026-07·09)로 재확인하고 시행 후에도 맞는 요약으로 고쳤습니다. 12-03부터 개정 조문이 자동으로 검색에 포함되고 기존 제19조는 적용 종료됩니다. 검토 기한이 지나도 자료는 사라지지 않고 "검토 기한 지남 · 원문 재확인 필요" 표시와 함께 검색됩니다. 다음 검토 기한 전에 법제처 원문을 다시 확인하세요.
