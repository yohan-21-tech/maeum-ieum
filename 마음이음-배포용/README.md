# 마음이음 0.2 — 교사·학부모 소통 MVP

가상 데이터로 체험하는 Next.js 서비스입니다. 실제 학생 정보나 상담 기록을 공개 데모에 입력하지 마세요. 원본 프로젝트와 분리한 작업본입니다.

## 실행
Node.js 22.16 이상에서 프로젝트 폴더를 열어 실행합니다.

```sh
npm ci
npm run setup
npm run dev:team
```

http://127.0.0.1:3001/login 접속. setup은 .env가 없으면 암호화 키를 생성합니다. 기존 .env는 보존합니다. DB와 암호화 키는 함께 백업하고 공개하지 마세요. 개발 서버 시작은 데이터를 초기화하지 않습니다.

교사로 체험 / 학부모로 체험 버튼을 누르면 방문자마다 별도의 가상 교사·학부모 계정 한 쌍이 만들어집니다. 체험 중 역할을 바꾸면 같은 짝 안에서 전환되며 다른 방문자의 기록은 보이지 않습니다. 예전 공용 계정(teacher@demo.local, parent@demo.local / Demo2026!)도 로그인할 수 있습니다.

## 구현 내용
- 검토된 공식 자료의 키워드 검색과 근거 결합: 출처·시행일·검토일·다음 검토일 표시. 미래 시행·만료·검토 기한 초과 자료 제외. 근거가 없으면 ‘근거 자료 없음’ 표시.
- 교사·학부모별 소통 초안, 감정 분석, 메시지 검토. CBR 가상 사례 24건은 실제 판례와 구별하고 유사도를 성공 확률로 표시하지 않습니다.
- 사람의 명시적 승인 뒤 메시지 전송과 리포트 공유. 수정하면 공유 승인 해제, 오래된 화면의 승인 방지. 관리자 연계는 초안까지만 생성합니다.
- 서버 권한 검사, 일회용 학생 연결 코드, 버전별 AI 동의·철회, 개인정보 마스킹, 주요 내용 암호화, 감사 기록, 요청 횟수 제한.
- 대화별 피드백·수정 제안, 개인 평가 현황, AI 기록 삭제, 근거 자료 화면, 단계별 데모.
- 키보드 모달 포커스·Escape, 입력 라벨, 본문 건너뛰기, 동작 감소 설정 지원.

## AI와 근거의 범위
API 키가 없으면 규칙 기반 데모 모드입니다. 실제 딥러닝 모델을 새로 학습하지 않았습니다. 선택적으로 서버 .env에 OPENAI_API_KEY를 설정하면 모델 호출을 사용하며, 오류·부적절한 출력은 대체 응답으로 처리합니다. 현재 공개 데모에는 API 키가 없습니다.

검색은 소규모 검토 자료의 키워드 방식이며 벡터 검색이나 실시간 법령 자동 갱신이 아닙니다. data/laws/sources.json에 자료를 관리합니다. 2026-11-03 기준 현재 사용 가능한 자료 3건과 미래 시행 자료 1건을 등록했습니다. 교육청 안내 사례는 실제 판결 결과가 아닙니다. 법률 적용을 보장하지 않습니다. 검토 기한이 지나면 재검증 후 날짜를 갱신해야 합니다.

## 검증
```sh
npm test
npm run typecheck
npm run evaluate
npm run build
npm audit --omit=dev
```
개발 서버 실행 상태에서 npm run smoke를 실행합니다. smoke는 로컬 서버에 가상 계정과 데이터를 생성합니다.

2026-11-03: 단위 테스트 44개 통과, 검색 평가 8/8, 로컬 HTTP 시나리오 41개 통과. 형식 검사와 운영 빌드 통과. 운영 의존성의 알려진 취약점 0건. 이는 법률 정확도·침투 테스트·대규모 부하 검증을 의미하지 않습니다.

## 공개 체험 및 운영 배포
현재 공개 체험은 Cloudflare 임시 터널로 별도 운영 서버 3002에 연결합니다. 컴퓨터·서버·터널이 켜져 있는 동안만 이용 가능하며 재시작 시 주소가 바뀔 수 있습니다. 원본 3000과 개발용 3001은 공개하지 않습니다.

운영 서버는 npm run build 이후 APP_ORIGIN을 공개 HTTPS 주소로 지정하고 npm start -- -H 127.0.0.1 -p 3002로 실행합니다. 공개 가상 데모를 허용할 때만 ENABLE_DEMO=1 및 ALLOW_PUBLIC_DEMO=1을 설정합니다. 일반 운영에서는 두 값을 0으로 지정합니다. DATA_ENCRYPTION_KEY는 base64로 인코딩한 32바이트 키가 필요합니다.

상시 호스팅을 위한 vercel.json, PostgreSQL 스키마·초기 마이그레이션을 준비했습니다. 호스팅 계정과 DB는 연결하지 않았습니다. 배포 전 관리형 PostgreSQL을 준비하고 DATABASE_URL, DATA_ENCRYPTION_KEY, APP_ORIGIN, ENABLE_DEMO=0, ALLOW_PUBLIC_DEMO=0을 호스팅에 설정하세요. 필요할 때만 AI 키를 추가합니다. 신규 DB에 npm run db:postgres:deploy를 실행하고 npm run build:postgres로 빌드합니다. 기존 SQLite 데이터를 자동 이전하지 않으며 실제 PostgreSQL 배포는 미검증입니다. SQLite 파일을 Vercel에 올려 운영할 수 없습니다.

## 남은 운영 과제
실제 학교 도입 전 조직별 인증·역할 승인, 보존 기간과 전체 계정 삭제 정책, 분산 요청 제한, 위변조 방지 감사 보관, 백업 복구, 부하·접근성 정밀 검사, 법률 담당자 검수가 필요합니다. 정규식 비식별화는 모든 개인정보를 탐지하지 못합니다. 일부 일지 감사 기록은 작업과 별도 기록됩니다. 관리자 기관 자동 전송은 구현하지 않았습니다.
